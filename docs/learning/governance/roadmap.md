# 学习路线图（v1.1 模板）

## 维护说明
1. 路线图按双线维护：`主线目标` 与 `复习目标`。
2. 阶段状态建议使用：`未开始`、`进行中`、`已完成`、`受阻`。
3. 每次会话后至少更新一项阶段状态或下一步动作。
4. 阶段完成必须提供会话证据，不得仅凭主观判断。
5. 每阶段默认 `复习债务上限=3`（高优先未完成项数量），超限时禁止进入下一阶段。

## 阶段项目里程碑（强制）
1. `M1 功能可运行`：核心功能可编译运行并通过基础用例。
2. `M2 边界与错误处理完善`：输入边界、错误路径、资源释放行为可验证。
3. `M3 复盘与重构说明`：说明关键设计决策、重构点与遗留问题。
4. 每个里程碑必须附证据链接（会话记录或代码说明）。
