## 维护说明
1. 所有经验条目必须关联来源会话。
2. 每条经验必须记录“适用前提”和“失效信号”，避免盲目复用。
3. 效果评分量表固定为 `0-5`：
   - `0` 无效
   - `1` 明显低效
   - `2` 有限帮助
   - `3` 有效
   - `4` 效果显著
   - `5` 高稳定高收益
4. 建议复用策略应有至少一次 `4/5` 以上证据；低于 `2/5` 的策略应标记停用或限制条件。
