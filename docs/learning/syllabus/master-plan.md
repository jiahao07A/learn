# C 语言学习总大纲（模板）

## 目标
1. 恢复并强化 C 语言基础能力，覆盖函数、指针、结构体、数据结构和手动内存管理。
2. 建立“讲解 -> 练习 -> 证据 -> 复盘 -> 复习”的闭环。

## 阶段映射
1. 阶段 1：基础回忆与诊断 -> 对应主题 `01-c-basics`。
2. 阶段 2：函数与指针强化 -> 对应主题 `02-functions`、`03-pointers`。
3. 阶段 3：结构体与内存管理 -> 对应主题 `04-structs`、`05-memory-management`。
4. 阶段 4：数据结构与调试 -> 对应主题 `06-data-structures`、`07-debugging`。
5. 阶段 5：综合项目实战 -> 对应 `docs/learning/projects` 与 `workspace/projects`。

## 节奏约束
1. 每次会话必须同时定义主线学习目标与复习目标。
2. 存在高优先复习项时，先复习后推进新主题。
