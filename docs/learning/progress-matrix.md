# 学习进展矩阵（v1.1 模板）

## 维护说明
1. 掌握等级固定为 `0-5`：
   - `0` 未接触或完全遗忘
   - `1` 仅有模糊印象
   - `2` 理解概念但难以独立应用
   - `3` 可在提示下完成并解释关键步骤
   - `4` 可独立稳定应用
   - `5` 可独立迁移应用并解释边界条件
2. 每条记录必须包含最近证据（会话文件名）。
3. 复习优先级由公式计算：
   - `复习分 = 0.6 * 最近错误率 + 0.4 * 遗忘间隔分`
   - `遗忘间隔分 = min(1, 距上次有效证据天数 / 目标复习间隔天数)`
4. 目标复习间隔（按掌握度）：
   - `0-1 => 1 天`
   - `2 => 2 天`
   - `3 => 4 天`
   - `4 => 7 天`
   - `5 => 14 天`
5. 复习优先级分层：
   - `复习分 >= 0.75`：高优先
   - `0.45 <= 复习分 < 0.75`：中优先
   - `复习分 < 0.45`：低优先
6. 若暂无可计算错误率，默认 `最近错误率=0.5`，并标记“证据不足待校准”。
7. 出现等级回退时必须在“阻塞原因”中说明，并在会话记录写修订说明。
